Gigabrain supplies sourced market context to your AI through a hosted MCP connection. The official skills guide your AI through setup, asset briefings and reviews of a supplied trade thesis.

Your AI supplies the reasoning. Gigabrain supplies market evidence, deterministic calculations, sources, timestamps and coverage information.

## Connect your AI

Start at [Connect Gigabrain](https://gigabrain.gg/connect), choose a supported client and follow its installation and browser OAuth sign-in instructions. The client manages the connection and OAuth credentials.

Ask for an asset briefing after connecting. Setup is complete when the client returns useful authenticated market context with sources, timestamps and coverage gaps. Installation and sign-in are intermediate steps.

<Note>
Core market context does not require connecting an AI-provider key in Gigabrain. Membership and shared usage limits still apply. Use the Connect page for current client support and access requirements.
</Note>

## Official workflows

| Skill | What it does |
|---|---|
| **setup** | Guides installation, browser OAuth, account access and a first context request. |
| **asset-briefing** | Produces a sourced briefing with freshness, missing coverage and conflicting evidence. |
| **trade-thesis-review** | Reviews a supplied thesis against market context and explicit assumptions. |

The integration is read-only. It does not manage wallets or place trades. You and your configured agent retain responsibility for strategy, sizing and execution. Missing data is reported as unavailable rather than treated as a neutral reading.

## Source and updates

[GigabrainGG/skills](https://github.com/GigabrainGG/skills) is the canonical public source. Shared workflow skills live in `integration/skills/`; the client packages and marketplace manifests are generated from that source.

Install the reviewed package using the client-specific Connect guide. Installed integrations update through the client's supported package update flow. Existing pinned revisions and release tags remain available; changing this repository does not silently update an installed package.

See the [integration maintenance guide](https://github.com/GigabrainGG/skills/blob/main/integration/README.md) for package generation, validation and release instructions.

## Existing SuperAgents

Hosted SuperAgent runtime skills are maintained separately in [GigabrainGG/superagent-skills](https://github.com/GigabrainGG/superagent-skills). That repository contains the legacy Brain client, wallet, trading, swap and agent-specific portfolio skills, together with the runtime's third-party sync manifest.

See [SuperAgent Skills](/core-features/superagent-skills) for the existing runtime's skill installation, authoring and management instructions.
